# Weather Z

A simple, free weather app for Android. No ads, no account, no tracking.

Made by Zoe, with Flutter/Dart.

## Features

- Current conditions, the next 48 hours and a 14-day forecast
- Weather for your location, plus any cities you add (swipe between them)
- Works offline with the last forecast it downloaded

## Data and privacy

- Weather data by [Open-Meteo.com](https://open-meteo.com/), licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- The app uses approximate location only, and only while it is open. Nothing is sent anywhere
  except to Open-Meteo to get the forecast. Read the full [privacy policy](PRIVACY.md).
